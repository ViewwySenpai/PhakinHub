PhakinHub Rust 6.1.2 — Windows x64

ใหม่ในรุ่นนี้: ลดข้อความเกริ่นใน UI
- นำแบนเนอร์ A little more control ออกจากหน้า Tools
- ตัดข้อความเกริ่นใต้หัวข้อทุกหน้าและคำอธิบายบนการ์ดเครื่องมือ
- ตัดข้อความแนะนำซ้ำในส่วน Timer, Katakuri, Hold E, Recording file และ Appearance
- ย่อข้อความเริ่มต้นในแถบสถานะเป็น Ready
- หน้า Tools แสดงรูป ชื่อ และปุ่มเปิดเครื่องมือในพื้นที่กระชับขึ้น

โลโก้และรูปเครื่องมือ (จากรุ่น 6.1.1)
- ใช้โลโก้เดียวกับไอคอนโปรแกรมแทนตัว P ด้านซ้ายบน
- ใช้ภาพที่ให้มาเป็นรูป Katakuri, Auto TS และ Timers ตามลำดับ
  แสดงทั้งเมนูด้านซ้ายและการ์ดเครื่องมือในหน้า Tools
- รักษาพื้นหลังโปร่งใสและสัดส่วนภาพ ใช้ได้กับธีม Light / Dark
- ฝังรูปทั้งหมดใน EXE ไม่ต้องวางรูปไว้ข้างโปรแกรม

ตรวจจับความเร็วและ Tournament (จากรุ่น 6.1.0)
- Auto TS > Game speed มี Manual / Automatic
  Manual เลือก x1 / x2 / x3 เองตามเดิม
  Automatic อ่านสีและรูปทรงของตัวเลข GAMESPEED ตรงมุมซ้ายล่างของ Roblox
  x1 = ขาว, x2 = เขียว, x3 = เหลืองเขียว ตามภาพตัวอย่างที่ให้มา
  ต้องอ่านได้ตรงกันหลายครั้งก่อนเปลี่ยนค่า ถ้าถูกบังหรืออ่านไม่ได้จะเก็บ x เดิม
  ค่านี้ใช้ปรับช่วงเวลาของ Auto TS ไม่ได้คลิกเปลี่ยนความเร็วในเกม
- Timers เพิ่ม Tournament Countdown เริ่ม 1,500 วินาที (25:00)
  เปิด Automatic start from Wave color ก่อนเริ่ม Tournament
  เมื่อพบข้อความสีส้มแบบ Tournament (Left]) จะเริ่มนับตามเวลาจริงเสมอ
  การปรับ x1 / x2 / x3 ไม่มีผลต่อเวลาที่เหลือ
  แยกหน้าต่าง, เปลี่ยนชื่อ และตั้ง Keybind ในหมวด Timers ได้
- Timer เริ่มจาก 1,500 วินาทีเมื่อพบข้อความ ไม่ได้อ่านตัวเลขเวลาที่เหลือจากเกม
  หากเปิดตรวจจับกลางรอบจะเริ่มที่ 25:00 จึงควรเปิดก่อนรอบเริ่ม
- เมื่อข้อความยังอยู่จะไม่เริ่มใหม่ซ้ำ ๆ รวมถึงหลังนับครบหรือถูกบังชั่วคราว
  กลับสู่หน้า -Wave- ปกติอย่างต่อเนื่องเพื่อรอรอบใหม่
  หรือกด Reset & re-arm เพื่อรีเซ็ตและรอจับ Tournament อีกครั้ง
  การกด Start/Pause/Reset ของ Timer เองจะกันการเริ่มอัตโนมัติซ้ำในรอบนั้น
- ระบบอ่านเฉพาะบริเวณ HUD ที่ตั้งไว้ ขณะหน้าต่าง Roblox อยู่ด้านหน้า
  ไม่ส่งคีย์หรือคลิก และไม่บันทึกภาพหน้าจอลงไฟล์
  เมื่อสลับออกจาก Roblox จะรอตรวจจับ แต่ Countdown ที่เริ่มแล้วนับต่อ
- พิกัดตั้งต้นอิงภาพ 1919x1079 ที่ให้มา และปรับตามขนาดพื้นที่เกม
  หากตำแหน่ง HUD ต่างกัน เปิด Speed detection area / Wave detection area
  เพื่อปรับ Left, Top, Width, Height เป็นเปอร์เซ็นต์ หรือ Restore area
  ระบบตรวจจับทั้งสองอย่างปิดไว้เป็นค่าเริ่มต้น

ฟอนต์รุ่นนี้
- ภาษาอังกฤษและตัวเลขใช้ Fredoka; ภาษาไทยใช้ Mitr
- ฝังฟอนต์ไว้ใน EXE แล้ว ใช้ได้ทั้งธีมมืด/สว่างและหน้าต่าง Timer
  ไม่ต้องติดตั้งฟอนต์ใน Windows หรือวางไฟล์ฟอนต์ไว้ข้างโปรแกรม

อัปเดตจาก Rust รุ่นเดิม
- ปิดโปรแกรมเดิมแล้วแทนที่เฉพาะ PhakinHub.exe เพื่อเก็บค่าตั้งและ Record เดิม
- หากใช้โฟลเดอร์ใหม่ ให้คัดลอก phakinhub-rust.ini และ recordings
  จากรุ่นเดิมมาวางข้าง EXE ใหม่ด้วย

เริ่มใช้งาน
1. แตก ZIP ลงโฟลเดอร์ที่เขียนไฟล์ได้ แล้วเปิด PhakinHub.exe
2. ไม่ต้องติดตั้ง Rust หรือ AutoHotkey เพื่อใช้โปรแกรม
3. เลือก Light / Dark ด้านขวาบน หรือ Settings > Appearance
   ธีมจะใช้ร่วมกับ Timer ที่แยกหน้าต่าง, Mini view และ Cockpit
   โปรแกรมจะจำธีมและค่าตั้งไว้ใน phakinhub-rust.ini ข้างไฟล์ EXE

Timer
- เปิดหน้า Timers แล้วคลิกชื่อเพื่อแก้ไข (รองรับชื่อภาษาไทย)
- + Add timer เพิ่ม TIMER 3, 4 และตัวถัดไป
- Delete ลบ Timer ที่เพิ่มเอง พร้อมล้าง Keybind ของตัวนั้น
  Timer เดิม 5 ตัวและ Tournament คงไว้ และ Timer ตัวอื่นไม่ถูกเปลี่ยนหมายเลข
- Detach แยกเป็นหน้าต่างอิสระ ลากแถบชื่อเพื่อย้ายไปตำแหน่งที่ต้องการ
- Dock หรือปิดหน้าต่าง Timer เพื่อนำกลับเข้าแผงหลัก
- ปุ่มของ Timer ทำงานตามลำดับ Start > Pause > Reset
  TIMER 1, TIMER 2 และ Timer ที่เพิ่มเองเป็นนาฬิกาจับเวลา
  TSUKU, GOJO/VAMPIRE และ LUFFY เป็นการนับถอยหลังตามค่าเดิม

Record & Playback
- เลือกชื่อไฟล์ แล้วกด Record เพื่อเริ่ม / หยุดบันทึก
- จับการกดและปล่อยคีย์บอร์ด ปุ่มเมาส์ 5 ปุ่ม และล้อเมาส์
- Capture mouse movement เปิด/ปิดการบันทึกตำแหน่งเมาส์
- การกดควบคุมในหน้าต่างแอปและปุ่มลัด Record / Playback ไม่ถูกบันทึก
- ตั้ง Record key และ Playback key แยกกันได้
- ใส่ความเร็วใน Speed multiplier แล้วกด Apply เช่น 0.25, 1, 1.75 หรือ 8
  รับเลขบวกที่มีค่าจำกัด และเปลี่ยนได้ขณะกำลัง Playback
- Loops = 0 เล่นซ้ำจนกดหยุด
- ถ้าเริ่ม Playback จากปุ่มในหน้าต่าง ให้สลับไปแอปเป้าหมายเพื่อเริ่มเล่น
  หรือใช้ Playback key ขณะอยู่ในแอปเป้าหมาย
- Open เปิดไฟล์ .rec เดิม / Save as บันทึกสำเนา
- เมื่อหยุด Playback โปรแกรมปล่อยคีย์และปุ่มเมาส์ที่กดค้างจาก Playback
- ถ้า Windows ปฏิเสธการส่งอินพุต ให้ตรวจว่าแอปเป้าหมายใช้ระดับสิทธิ์เดียวกัน

Katakuri / Auto TS / Auto actions
- Katakuri มีตัวเลือก 3 ถึง 8 พร้อมสถานะ ON/OFF, Interval และเวลาคูลดาวน์
- สวิตช์ใช้เลือกชุด แล้วกด Start เพื่อเริ่ม หรือ Start this count เพื่อเริ่มเฉพาะตัว
- Auto TS มี Cursor, Point และ Placement พร้อมค่าช่วงเวลาและจุดคลิก
- Auto actions มี Auto click, Auto key press, Hold E และ Upgrade ตามเดิม
- คลิกอัตโนมัติจะข้ามพื้นที่ของ PhakinHub เอง
  Auto key / Upgrade รอให้สลับไปหน้าต่างเป้าหมายก่อนส่งคีย์
- Stop all หยุดการส่งอินพุตอัตโนมัติ, Record และ Playback
  Timer จับเวลาแยกต่างหาก หยุดได้จากปุ่มของแต่ละ Timer

Keybinds
- Settings > Keybinds เลือกหมวด Auto TS, Katakuri, Timers,
  Record / Playback, Auto actions หรือ Panel / System
- Set แล้วกดคีย์บอร์ดหรือปุ่มข้างเมาส์ภายใน 30 วินาที
  หรือเลือกปุ่มจากรายการ Choose key ได้โดยตรง
- รับคีย์จากหน้าต่างแอปโดยตรงด้วย และรองรับคีย์จากโปรแกรม remap
- Esc หรือ Cancel ยกเลิกโดยเก็บค่าเดิม; Clear ล้างปุ่ม
- หนึ่งปุ่มผูกได้หนึ่งฟังก์ชัน หากใช้ปุ่มซ้ำจะย้ายไปฟังก์ชันใหม่
- ตั้ง Stop All Actions ในหมวด Panel / System ได้
- ค่าเริ่มต้นไม่มีปุ่มลัดจนกว่าจะตั้งค่าเองหรือนำเข้าค่าเดิม

ใช้ค่าจากรุ่น AutoHotkey เดิม
- ก่อนเปิด Rust ครั้งแรก ให้วางสำเนา config.ini และโฟลเดอร์ recordings
  ของรุ่นเดิมไว้ข้าง PhakinHub.exe
- หากยังไม่มี phakinhub-rust.ini โปรแกรมจะอ่าน config.ini ให้
- โปรแกรม Rust บันทึกลง phakinhub-rust.ini โดยไม่เขียนทับ config.ini เดิม
- รองรับ config.ini แบบ UTF-8 และ UTF-16 LE รวมถึงรายชื่อ Timer ที่มีการลบข้ามเลข
- หากไฟล์ Record เดิมชี้ไปที่ตำแหน่งอื่น ให้ใช้ Open เพื่อเลือกไฟล์ใหม่

ซอร์สโค้ดและการ Build
- source/ มีซอร์ส Rust, Cargo.toml และ Cargo.lock
- ใช้ Windows x64, Rust toolchain แบบ MSVC และ C++ Build Tools
- เข้าโฟลเดอร์ source แล้วรัน:
    cargo test --locked
    cargo build --release --locked
- ไฟล์ที่ได้: target/release/phakinhub-rust.exe
- ใช้ eframe/egui สำหรับหน้าต่าง native และ Windows API สำหรับอินพุต
- อ่านเงื่อนไขของไลบรารีที่ THIRD_PARTY_NOTICES.txt
